# skolavela.app

Dočasná oznamovací stránka na [skolavela.app](https://skolavela.app): aplikace Velappky se přesunuly na [velappky.cz](https://velappky.cz).

Stránka sama nepřesměrovává. Když někdo přijde se starou cestou nebo hashem (např. `/prijimacky/` nebo `/#/cestina`), tlačítko odkáže na stejnou adresu na velappky.cz. Soubor `404.html` zajistí, že i záložky na podstránky uvidí oznámení místo chybové stránky GitHubu.

Doména později poslouží interním aplikacím pro učitele a žáky. Tuto stránku jde snadno nahradit.

Nepoužívejte tento repozitář pro [velappky.cz](https://velappky.cz) — ten běží v `skolavela/skolavela.github.io`.
